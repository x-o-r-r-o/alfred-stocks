# Stocks

Watchlist quotes and quick ticker lookup.

> **Status:** planned — not yet functional. See [PLAN.md](PLAN.md).

## Usage

Watchlist quotes and quick ticker lookup via the `stock` keyword.

![Stocks results in Alfred](images/stock.png)

* <kbd>↩</kbd> Primary action.
* <kbd>⌘</kbd><kbd>↩</kbd> Secondary action.
* <kbd>⌘</kbd><kbd>Y</kbd> Quick Look.

Every keyword can be changed in the Workflow’s Configuration.

## Development

```bash
./build.sh   # -> dist/alfred-stocks-<version>.alfredworkflow
```
